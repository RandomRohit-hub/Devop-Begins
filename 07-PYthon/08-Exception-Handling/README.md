# Module 08: Exception Handling

Defensive programming and crash-proofing automation scripts with Python's exception handling mechanics.

## 📄 Scripts Included

* **[`try1.py`](./try1.py)**: Basic `try` / `except` block catching runtime errors.
* **[`try2.py`](./try2.py)**: Handling specific exceptions (e.g., `ZeroDivisionError`, `ValueError`).
* **[`try3.py`](./try3.py)**: Using `else` and `finally` blocks for reliable cleanup actions.
* **[`try4.py`](./try4.py)**: Multiple exception handling and extracting exception message text.

## 🚀 Execution
```bash
python3 try1.py
python3 try4.py
```
