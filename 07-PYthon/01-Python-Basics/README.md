# Module 01: Python Basics

Foundational Python concepts for DevOps engineers: syntax basics, datatypes, slicing, and variable assignments.

## 📄 Scripts Included

* **[`first_script.py`](./first_script.py)**: Basic Python script hello world and execution demonstration.
* **[`printing.py`](./printing.py)**: Print formatting, commas, concatenation, and strings.
* **[`quotes_and_comments.py`](./quotes_and_comments.py)**: Single, double, triple quotes, and single/multiline comments.
* **[`variables.py`](./variables.py)**: Variable assignment, dynamic typing, and memory pointers.
* **[`datatypes.py`](./datatypes.py)**: Numbers (int, float), Strings, Lists, Tuples, Dictionaries, and Booleans.
* **[`slicing.py`](./slicing.py)**: String and list indexing, slicing ranges `[start:stop:step]`, and reversal.

## 🚀 Execution
```bash
python3 first_script.py
python3 slicing.py
```
