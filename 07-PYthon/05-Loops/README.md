# Module 05: Loops

Iteration techniques in Python for processing lists, servers, dictionaries, and repetitive tasks.

## 📄 Scripts Included

* **[`loops.py`](./loops.py)**: `for` loops and `while` loops iterating across data structures.
* **[`loops_nested.py`](./loops_nested.py)**: Nested loops for matrix or multi-dimensional collection iteration.
* **[`break_example.py`](./break_example.py)**: Terminating loops early with `break`.
* **[`continue_example.py`](./continue_example.py)**: Skipping current iterations with `continue`.
* **[`break_and_continue.py`](./break_and_continue.py)**: Practical examples combining `break` and `continue`.

## 🚀 Execution
```bash
python3 loops.py
python3 break_and_continue.py
```
