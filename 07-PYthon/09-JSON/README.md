# Module 09: JSON Data Serialization

Working with JSON data formats, commonly used in cloud APIs, CI/CD telemetry, and configuration management.

## 📄 Scripts Included

* **[`learn_json.json`](./learn_json.json)**: Structured sample JSON document with nested objects, arrays, booleans, and strings.
* **[`parse_json.py`](./parse_json.py)**: Loads and parses JSON files using Python's standard `json` library (`json.load`, `json.dumps`).

## 🚀 Execution
```bash
python3 parse_json.py
```
