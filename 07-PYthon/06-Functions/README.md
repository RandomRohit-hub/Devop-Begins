# Module 06: Functions

Creating modular, reusable code blocks, passing arguments, and structuring Python modules.

## 📄 Scripts Included

* **[`functions.py`](./functions.py)**: Basic function definitions (`def`), parameters, and return values.
* **[`functions_keywords.py`](./functions_keywords.py)**: Positional vs keyword arguments and default values.
* **[`variable_length_arguments.py`](./variable_length_arguments.py)**: Arbitrary positional arguments (`*args`).
* **[`kwargs.py`](./kwargs.py)**: Arbitrary keyword arguments (`**kwargs`).
* **[`modern.py`](./modern.py)**: Standalone reusable utility module with exported functions.
* **[`call_modern.py`](./call_modern.py)** & **[`call_modern_direct.py`](./call_modern_direct.py)**: Importing and invoking functions from other modules.

## 🚀 Execution
```bash
python3 functions.py
python3 call_modern.py
```
