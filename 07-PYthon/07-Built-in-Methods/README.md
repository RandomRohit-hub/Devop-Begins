# Module 07: Built-in Methods

Explores common built-in methods for strings, lists, dictionaries, and tuples.

## 📄 Scripts Included

* **[`built_in_methods.py`](./built_in_methods.py)**: Demonstrates:
  - String manipulation (`.upper()`, `.lower()`, `.strip()`, `.replace()`, `.split()`)
  - List methods (`.append()`, `.extend()`, `.insert()`, `.pop()`, `.remove()`, `.sort()`)
  - Dictionary operations (`.keys()`, `.values()`, `.items()`, `.get()`)

## 🚀 Execution
```bash
python3 built_in_methods.py
```
