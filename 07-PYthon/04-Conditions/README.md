# Module 04: Conditions

Flow control and decision-making using conditional statements in Python.

## 📄 Scripts Included

* **[`conditions.py`](./conditions.py)**: `if`, `elif`, and `else` blocks with boolean conditions.
* **[`condition_vars.py`](./condition_vars.py)**: Dynamic conditionals inspecting variable states and collections.

## 🚀 Execution
```bash
python3 conditions.py
python3 condition_vars.py
```
