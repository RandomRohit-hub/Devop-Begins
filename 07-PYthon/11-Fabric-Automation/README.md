# Module 11: Fabric Automation

Multi-node remote orchestration and deployment over SSH using the Fabric Python library.

## 📄 Scripts Included

* **[`fabfile.py`](./fabfile.py)**: Automates remote server tasks:
  - Connecting via SSH credentials/keys
  - Running remote commands (`run`, `sudo`)
  - Uploading/downloading deployment assets (`put`, `get`)
  - Restarting web servers and daemon services

## 🚀 Execution
```bash
fab --help
# Or run with Python fabric CLI runner
```
