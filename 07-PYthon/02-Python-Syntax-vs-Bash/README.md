# Module 02: Python Syntax vs. Bash

A side-by-side comparison between Shell scripting (Bash) and Python syntax, focusing on indentation, block delimiters, and logic structures.

## 📄 Scripts Included

* **[`bash_syntax.sh`](./bash_syntax.sh)**: Shell script utilizing `if`/`then`/`fi` and block tokens.
* **[`python_syntax.py`](./python_syntax.py)**: Equivalent Python script demonstrating whitespace indentation and colons (`:`) in place of block braces or keywords.

## 🚀 Execution
```bash
bash bash_syntax.sh
python3 python_syntax.py
```
