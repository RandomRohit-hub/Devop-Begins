# Main Repository: DevOps CI/CD Learning & Projects

Welcome to the `ci` branch environment! This directory serves as the root for your continuous integration setups and projects. 

## Structure Overview

This repository has been divided into practical project implementations and a dedicated learning knowledge base:

* **`ci/`** - The definitive DevOps Knowledge Base. Contains guides, scripts, architecture diagrams, and concepts from the video training spanning Jenkins, SonarQube, Nexus, and more.
* **`freestyle-build-foundation/`** - The initial project focused on mastering Jenkins Freestyle jobs. This hands-on project serves as the foundation for learning UI-driven configurations and artifact management.
* **`pipeline-as-code-mastery/`** - The advanced project utilizing fully automated Jenkinsfiles. This contains the infrastructure to execute tests, code analysis, and packaging strictly via code, enabling better version control and developer workflows.

## How to use

1. If you are learning the concepts or need to configure a new Jenkins/SonarQube/Nexus instance, consult the **`ci/`** folder.
2. If you are experimenting with Jenkins Freestyle setups, make your modifications within **`freestyle-build-foundation/`**.
3. If you want to refine multi-stage automated pipelines or tweak the `Jenkinsfile`, work inside **`pipeline-as-code-mastery/`**.

Enjoy building!
