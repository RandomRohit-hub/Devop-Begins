### Basic Git Commands Overview

*   **Initialize Repository:** `git init`
*   **Check Status:** `git status`
*   **Stage Files:** `git add .` or `git add <file>`
*   **Commit Changes:** `git commit -m "commit message"`
*   **Push Code:** `git push origin <branch-name>`
